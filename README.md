# asset-templates（AI 视频资产提示词模板库）

无状态、无确认门的资产模板库，供 [ai-video-pipeline](https://github.com/yang1996202-cpu/ai-video-pipeline) 在资产/视频阶段直接调用。

## 五张模板

| 模板 | 用途 | 画幅 |
|---|---|---|
| A | 9:16 角色母板（16 字段：骨相锁定/命运气质/五官皮肤发型服装…） | 9:16 |
| B | 16:9 角色设定板（正面无头服装+背面+面部特写三视图） | 16:9 |
| C | 3:4 关键道具母板（产品档案照；道具出现≥2次跨组才立资产） | 3:4 |
| D | 16:9 场景空间底图（锁空间/地标/主光/前中后景，不锁机位） | 16:9 |
| E | 组合视频四段式（15s 多镜，逐镜切点+%%@音频引用+FAST参数基准） | 16:9 |

## 来源

- A/B/C 萃取自 chaoge-assets-trial（超哥AI导演）v1.3.0 体验版 P2 模板段（剥离获客壳：确认门/终止态/广告）
- D 萃取自 ai-film-general-skill（AJ）image-asset-workflow §4 场景资产法
- E 萃取自 AJ cinedance 四段式 + shot-contract 首帧占位/参考职责（2026-10-20《长命》实战固化）

原 skill 均保留，按需翻完整案例。

## 实战验证

《长命》（2026-10-19~20）：A 出 5 母板（含儿童角色 v3 概念设定图措辞过审核）、B 出 2 设定板、C 出糖/信 2 道具、D 出 4 场景、E 出 9 组合视频（31镜/101s）。
